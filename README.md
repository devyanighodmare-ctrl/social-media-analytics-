
# 📊 Social Media Engagement Analysis

### End-to-End Data Analytics Project | Python • Pandas • Power BI

---

## 📌 Project Overview

This project focuses on analyzing social media engagement data to identify patterns, trends, and meaningful business insights.

The dataset contains **12,000 records** covering different social media platforms, campaigns, topics, brands, products, and sentiment categories.

Python and Pandas were used for data cleaning, preprocessing, and exploratory data analysis (EDA), while Power BI was used to develop an interactive dashboard for visualizing key performance indicators and business insights.

---

## 🎯 Project Objectives

- Analyze social media engagement across different platforms.
- Identify top-performing posts and campaigns.
- Understand audience sentiment and engagement patterns.
- Analyze day-wise and monthly posting trends.
- Identify popular hashtags, brands, and products.
- Develop an interactive Power BI dashboard.
- Generate meaningful business insights from raw data.

## ⚙️ Project Workflow

**1. Data Collection**
- Imported the social media engagement dataset.
- Dataset contains 12,000 rows and 28 original columns.

**2. Data Cleaning**
- Checked and removed duplicate records.
- Handled missing values.
- Removed unnecessary spaces from text columns.
- Converted timestamp into datetime format.

**3. Feature Engineering**
- Created a `total_engagement` column.
- Calculated engagement ranking for posts.

**4. Exploratory Data Analysis (EDA)**
- Analyzed likes, comments, shares, and impressions.
- Compared platform-wise engagement.
- Analyzed campaign and topic performance.
- Explored sentiment and emotion categories.
- Identified popular hashtags.
- Studied monthly and day-wise engagement trends.

**5. Data Visualization**
- Created histograms, bar charts, pie charts, line charts, scatter plots, box plots, correlation heatmaps, and pair plots.

**6. Power BI Dashboard**
- Imported the cleaned CSV dataset.
- Created six DAX measures.
- Developed KPI cards and interactive charts.
- Added a time-period slicer.
- Presented key business insights.

## 💡 Key Business Insights

| Analysis | Key Finding |
|---|---|
| Highest Total Engagement Platform | YouTube |
| Highest Average Engagement Platform | Instagram |
| Top Performing Campaign | CyberMonday |
| Highest Average Campaign Engagement | SummerDreams |
| Highest Average Engagement Topic | Returns |
| Highest Average Engagement Brand | Amazon |
| Highest Average Engagement Product | Kindle |
| Best Performing Day | Sunday |
| Most Used Hashtag | #Fitness |

### Important Findings

- YouTube recorded the highest total engagement of approximately **9.76 million**.
- Instagram achieved the highest average engagement per post of approximately **4,046.41**.
- CyberMonday generated the highest campaign engagement of approximately **2.29 million**.
- Sunday recorded the highest average daily engagement of approximately **4,017.27**.
- #Fitness was the most frequently used hashtag with **885 occurrences**.
