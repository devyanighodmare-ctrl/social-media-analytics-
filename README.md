# Social Media Engagement Analysis

## Project Overview
This project analyzes 12,000 social media records using Python, Pandas and Power BI to identify engagement trends and business insights.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI

## Key Analysis
- Platform-wise engagement
- Campaign performance
- Sentiment analysis
- Day-wise engagement
- Hashtag analysis

## Key Findings
- YouTube recorded the highest total engagement.
- Instagram had the highest average engagement.
- Sunday recorded the highest average daily engagement.
- #Fitness was the most frequently used hashtag.

## Dashboard
An interactive Power BI dashboard was developed with KPI cards, charts and a time-period slicer.
